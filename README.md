# SubSync - Subscription Management System

A full-stack subscription tracking application built with React and Node.js.

## 🚀 Features

- Track multiple subscriptions
- View subscription details and renewal dates
- Add, edit, and delete subscriptions
- Responsive UI design

## 🛠️ Tech Stack

**Frontend:**
- React + Vite
- Modern JavaScript (ES6+)

**Backend:**
- Node.js + Express
- MongoDB (Database)

**DevOps:**
- Docker & Docker Compose
- Jenkins CI/CD Pipeline
- DockerHub Registry

## 📦 Project Structure

```
OCC-subsync/
├── backend/          # Node.js API
├── frontend/         # React application
├── Jenkinsfile       # CI/CD pipeline
└── docker-compose.yml # Container orchestration
```
